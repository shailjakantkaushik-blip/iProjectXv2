Controls you can take to a review

Identity

Authenticator MFA (TOTP) required for every user. Optional per-organisation SAML SSO. Optional IP / CIDR organisation restriction. Hardened sessions with PKCE — access tokens are not stored in localStorage.

Isolation

Row-level security isolates every organisation. Project Access grants (Strategic Alignment, program, functional area, project, stream) apply to pages, KPIs, dropdowns, and Home — not just the project list.

Residency · optional BYOD

Host tenant registers on your PostgREST-compatible database. Auth and control plane stay on iProjectX. Use when data must not sit on the shared platform store.

In-house AI

Default portfolio Q&A runs inside the organisation session on live PMO data. An approved Open AI model is available only if the organisation requests it — never on by default, never a silent leak.

Browser & edge

Content-Security-Policy, HSTS, and a locked-down session model. Platform security events cover login, logout, and failures.

Evidence

Admin audit log. One-click Excel evidence packs for auditors. Role-based access for org admins, PMs, and platform operators. White-label branding does not weaken tenancy.
