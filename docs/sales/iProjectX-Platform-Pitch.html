Leaders do not lack slides. They lack a live, explainable portfolio. By the time the pack is pretty, the money has already moved. iProjectX exists so the board meeting is not a reconstruction.

Without iProjectX

  • RAG is typed by hand so the pack can go out.
  • The deck is last month’s weather. Overruns appear at year-end.
  • Gate approvals live in email. RAID rots in a shared workbook.
  • The same person is booked five times. Capacity is a conversation.
  • Budget, forecast, and actuals live in three files that disagree.
  • Executives see a neighbour’s RAID because access is a shared login.

With iProjectX

  • Health is calculated. A named override is marked so the room can see it.

  • Budget, Plan, Forecast, Demand, and Actuals have one write path each.
  • Project Access scopes pages, KPIs, dropdowns, and Home.
The buyer is not shopping for more columns. They are buying an early-warning system that can defend every red, every dollar, and every hold in the room.

People, capacity, time

Capacity is a number — after weekends, holidays, and leave

Estimation Planning

The estimate board. Select a role, put a named person on a stream phase. Effort is hours / days / weeks. Working days already exclude weekends, location holidays, and that person’s dated leave.

If assigned hours exceed remaining capacity: Save anyway? Confirming still saves, toast-warns the planner, and notifies the person’s linked login and resource manager.

Apply planned baseline writes Plan only: planned dates, CapEx/OpEx plan, Planned FTE. It does not write actuals.

Resources

Name, role, location, hours/day, cost rate, resource manager. Location drives public holidays (* is org-wide). Hours/day is the Over / Optimal / Under cap.

Utilisation is allocation vs demand vs actual. Monthly capacity is working days × hours/day — not a flat week × 4.33.

Holidays & leave live on Resources. Annual / Sick / General with inclusive dates. Geography holidays match the person’s location.

Timesheets

Week grid against assigned work items. Daily totals flag Over / Optimal / Under. Submit → PM then Resource Manager approve. Only approved hours become Actual FTE $ (hours × rate). Month plan respects the same holiday/leave calendar.

Load chips

Optimal is ≥ 60% of the daily cap. Over is above the cap. A dated window whose weekdays are all leave or holidays is Over — weekend-only windows are not. That is what stops “they’re on leave, keep booking.”

Govern

Gates, RAID, and decisions — with evidence, not email

Stage Gates

Pass, hold, or reject with a checklist. The decision is stored on the project. Approvals become Decisions. A late gate can raise phase Forecast; it does not silently rewrite Budget or Plan.

Investment Committee

Portfolio-level go / hold / stop with financials on the same page. Use it when the ask is bigger than a stream gate — funding, stop, or reshape the envelope.

RAID

Risks, Actions, Issues, Decisions — plus stakeholders and lessons. Filter by project, stream, forum, sponsor, and gate. Critical and overdue items escalate. Daily digests keep the queue moving. My Work shows items waiting on you.

Governance Channel

Forums and cadence windows so steering is a rhythm, not a surprise. RAID can be scoped to the forum that owns it.

Dependencies & Schedule CPM

Project-to-project and work-item links. Critical path on Schedule CPM. Delay what-ifs belong in Executive Intelligence.

Risk Roadmap · Releases · Lessons
