# iProjectX Information Security Management System (ISMS)

This folder holds the formal policies and registers required for **SOC 2 Type II**, **ISO 27001**, and enterprise procurement readiness.

| Document | Purpose |
|----------|---------|
| [INFORMATION_SECURITY_POLICY.md](./INFORMATION_SECURITY_POLICY.md) | Top-level security policy |
| [ACCESS_CONTROL_POLICY.md](./ACCESS_CONTROL_POLICY.md) | Identity, MFA, RBAC, joiner/mover/leaver |
| [LOGGING_AND_MONITORING.md](./LOGGING_AND_MONITORING.md) | Audit events, login monitoring, retention |
| [INCIDENT_RESPONSE.md](./INCIDENT_RESPONSE.md) | Security incident handling |
| [VENDOR_SUBPROCESSORS.md](./VENDOR_SUBPROCESSORS.md) | Third-party processors (GDPR/APP) |
| [RISK_REGISTER.md](./RISK_REGISTER.md) | Living risk register |

**Owner:** Platform / Security lead  
**Review cycle:** At least annually, or after material system changes  

Technical controls are implemented in application code and Supabase RLS. These documents are the management-system layer auditors will request.
